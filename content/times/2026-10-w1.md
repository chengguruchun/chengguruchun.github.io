# Agent Observability

Agent 从 demo 走向可用系统后，最大的工程瓶颈不再是模型能力，而是多步工具调用与检索链路出错时无法定位。可观测性把 trace、span、token 与工具调用标准化，直接决定本站 Agent 主线能否稳定迭代。OpenTelemetry 的 GenAI 语义约定与 LangSmith 已给出可点开的落地路径，与近期记忆主题互补而不重复。
