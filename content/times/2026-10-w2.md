# Agent Sandboxing

Agent Sandboxing 直接回应 Agent 从对话走向执行后的核心工程问题：如何约束文件系统、网络与命令权限。它承接本站 Agent 主线，与近期 Agent Observability 形成“观测—约束”互补，且能落到工具调用权限、最小权限与运行时隔离的具体实现。相比偏评测的候选，它更贴近系统与安全主线，证据链完整且可操作。
