# Agent Registry：能力发现、版本契约与信任边界

- tags: Agent, Registry, 契约, 基础设施
- date: 2026-09-02

## 问题

当 Agent 互相调用，硬编码终点会迅速腐烂。需要注册中心——但不是只存 URL。

## 观点

Agent Registry 至少包含：

- **能力描述**：输入/输出 schema、工具集合、模态
- **版本与兼容**：契约演进，而不是静默破坏
- **信任与权限**：谁可以发现、谁可以调用
- **运行时提示**：延迟、成本、成功率、区域

它是服务发现、模型目录与安全策略的交叉点。

## 开放问题

能力描述该用自然语言、结构化 schema，还是可执行测试作为契约？
