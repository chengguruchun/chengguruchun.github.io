Concepts · 核心概念

比具体模型更稳定的抽象：理解这些概念，有助于把模型能力放进真正的 Agent 系统。

Attention

让模型根据上下文动态决定信息之间的关联强度。

Knowledge Distillation

把 teacher model 的行为或知识迁移给更小的 student model。

In-context Learning

不更新模型参数，仅通过上下文示例改变当前任务表现。

RLHF

利用人类偏好信号对语言模型行为进行对齐。

RAG

把模型与外部可检索知识连接，降低纯参数记忆的限制。

Tool Use

让模型调用搜索、代码、数据库、API 等外部能力，而不局限于生成文本。

Context Engineering

围绕模型当前状态组织信息、历史、工具结果与约束，让下一步生成更可靠。

Test-time Compute

把更多计算预算放在推理阶段，通过搜索、验证或多次采样提升任务表现。

Agent

模型从一次性回答走向感知、规划、行动、反馈与迭代。

Agent Runtime

让 Agent 像服务一样被调度、执行、观测、恢复与验证，是这里正在持续研究的系统层。
