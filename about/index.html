About Me · 研究画像

从分布式系统走向 Agent 基础设施。

我是 chengguruchun，一名在杭州工作的软件工程师。我的关注点，是如何把确定性软件系统中的工程纪律，迁移到具有概率性、工具调用和反馈闭环的 Agent 系统中。

我是谁

这些年，我在电商、IoT 和工业系统中写软件，也持续观察不同领域之间的共同结构：目标如何被表达，系统如何被约束，结果如何被验证，失败如何反馈到下一轮行动。

现在，我把这条经验带到 AI Agents / Infrastructure：不只讨论模型能生成什么，也关注 Agent 如何被调度、被授权、被评测，并最终在真实环境中完成任务。

我正在研究的三个问题

01 · Agent Infrastructure

任务如何可靠地完成？

关注 Control Plane、Runtime、Tool Gateway、Policy、Approval、Eval 与 Outcome。

02 · Loop Engineering

一次回答如何变成闭环？

用 Goal → Action → Observation → Gap → Adjustment 描述会行动的智能系统。

03 · Experiment Engineering

概率性如何被研究？

用假设、对照、评测和真实结果，替代对单次 Prompt 经验的依赖。

我如何工作

我习惯用类比建立模型，用实验检验假设，再把结论放回工程实践中观察。一个想法不是结论，而是一个需要面对反例、成本和真实结果的假设。

我的工作路径

提出问题 → 建立假设 → 寻找跨领域对应关系 → 落到工程实践 → 观察结果 → 修正理解。

这条方法已经沉淀在本站的内容中：可以从大模型实验方法开始，再阅读Kubernetes × Agent 的控制面类比，最后查看复杂系统视角。
