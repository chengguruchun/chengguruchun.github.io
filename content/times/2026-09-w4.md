# Agent Memory Benchmark

长期记忆的讨论已从架构设计转向可度量：没有统一评测，记忆模块的取舍只能靠直觉。LOCOMO、LongMemEval、MemBench 等基准把超长对话、时间推理与知识更新变成可复现的分数，直接决定本站 Agent 记忆主线该保留哪些模块、砍掉哪些开销。选它，是把上周的架构讨论落到可回归的工程验收上。
