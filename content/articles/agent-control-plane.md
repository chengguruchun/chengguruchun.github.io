# Agent Control Plane：把智能体当成可治理的运行时

- tags: Agent, Control Plane, 分布式系统, 可观测性
- date: 2026-08-20

## 问题

多数「Agent 应用」停在提示词与工具调用。一旦进入生产，缺少的不是更聪明的模型，而是**控制面**：谁被调度、以什么策略执行、如何观测、如何停止。

## 观点

把 Agent 视为一种带目标的工作负载。控制面负责：

1. **意图准入**：目标是否合法、预算是否足够
2. **执行编排**：单 Agent / 多 Agent、同步或异步
3. **策略与护栏**：工具白名单、数据边界、人机回环
4. **观测与审计**：轨迹、成本、失败模式
5. **生命周期**：挂起、恢复、终止、回放

## 开放问题

控制面应该靠近模型运行时，还是像服务网格一样旁路？多租户下的策略语言该有多强表达力？
