# Agent 记忆：状态、知识，还是日志？

- date: 2026-08-22
- tags: Thinking, Memory, 状态管理

## Question

「给 Agent 加记忆」常被实现成向量库检索。但系统里的记忆至少有三种角色：短期工作状态、可回放的事件日志、可共享的长期知识。混为一谈会导出错误的一致性与权限模型。记忆到底是状态、知识，还是日志？

## My Thinking

分层比选单一存储重要：

1. **工作记忆（状态）：** 当前任务上下文，强一致、短生命周期，失败应可丢弃或显式恢复。
2. **情景记忆（日志）：** 可回放轨迹，追加写为主，用于审计、调试与「为什么这么做」。
3. **长期知识（知识库）：** 可检索、可版本化，偏最终一致；写入需治理，不是每次推理都直接落库。

一致性责任应跟着层走：状态层保证任务内正确；日志层保证可解释；知识层保证可演化而不静默污染。
