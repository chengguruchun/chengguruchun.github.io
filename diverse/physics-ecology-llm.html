物理学 × 生态学：对复杂系统的一个思考

思路 2026-09-02发表 2026-09-06作者 chengguruchunComplex SystemsAgentLLM

Question

物理学与生态学，是否代表两种理解世界的方式？当 LLM 与 Agent 从「函数」长成「多体互动」，设计系统时该用哪一种科学直觉——寻找公式，还是理解关系、反馈与演化？

My Thinking

物理学和生态学，更像两副透镜，而不是互相取消的答案。叠在一起，才容易看清复杂系统，以及 LLM / Agent 正在逼近的形态。

物理学：规律与可重复

物理学里，常见的是相对稳定、可重复、可以高度抽象的规律。给定初始条件和边界条件，系统往往可以用明确的数学关系描述。

  • 力对应加速度
  • 能量对应状态变化
  • 初始条件加规律，常常导向可预测的结果

因此，物理学很容易长出一种偏确定性的世界观：先抓住规律，再在边界内推演状态，最后得到结果。

生态学：关系、反馈与演化

生态系统完全不同。一个生态系统里通常同时存在：大量不同类型的个体、个体之间不断互动、环境持续变化、局部影响整体、整体又反过来影响个体，以及大量反馈循环、随机性与历史依赖。

所以很难说「给定 A，一定得到 B」。更多时候只能说：A 会提高 B 出现的概率。

物理系统更容易寻找「规律」；生态系统更需要理解「关系、反馈和演化」。

从确定性到概率性

世界并不一定只有一种科学解释方式。物理学更接近「规则，然后状态，然后结果」；生态系统更像个体、关系、环境与反馈缠在一起，系统状态再反向塑造个体。

因此，复杂系统的核心往往不是「找到一个公式，然后计算最终答案」，而是理解参与者、关系、反馈，以及系统如何随时间演化。

LLM：落在两种透镜之间

LLM 让这两种透镜同时变得刺眼。从训练与采样看，它高度概率性：同一提示，输出可以不同；质量常常只能用区间与评测分布来谈。这更接近生态里的变异与选择压力，而不是经典力学里的单值轨迹。

但从工程封装看，人们又总想把它按物理系统来用：给定输入，期望稳定输出；给定工具调用，期望可复现副作用。于是冲突出现了——用确定性工作流的语言，去编排概率性的智能体。

所以 LLM 本身已经在逼迫一种综合：既承认内核的不确定，又在边界上建立可治理的约束。

AI Agent：从函数到小型生态

简单软件系统更像物理系统：输入进入函数，得到输出。「输入 X，输出 Y」往往成立。

Agent 系统却越来越像一个小型生态系统。参与者至少包括 Agent 与 Agent、Tool、Environment、Memory、Human。每一个 Agent 都可能改变环境，环境变化又会影响其他 Agent；记忆会改写后续决策，工具会引入不可轻易回滚的副作用，人会在回路中改写目标与约束。

因此，未来的 Agent 系统很可能不是简单的 Workflow Engineering，而越来越接近 Complex System Engineering。

需要研究的就不只是 Agent 能做什么、Tool 有哪些、Prompt 怎么写，还包括：关系如何形成、如何通信、如何竞争与合作、如何形成反馈、如何避免失控、如何持续演化，以及如何衡量整个生态系统，而不是单个 Agent。

Control Plane：秩序层，而不只是执行层

Agent 数量越多，就越像生态系统。这时往往需要类似 Kubernetes Control Plane 的一层。

Control Plane 并不一定直接完成任务。它更像在维持整个系统的目标、状态、资源与秩序：调度谁出现、谁能调用什么、失败如何收敛、观测落在哪里。Agent、Tool、Memory 都在环境中互动；Control Plane 则像在给这片「生态」提供可治理的边界与反馈通道。

这和生态系统中的「环境 + 反馈机制」有一点非常有意思的类比——类比不是等式，但它提示：治理层与执行层应当分开看。这也解释了为什么 Control Plane 会成为 Agent 基建里反复出现的议题。

综合思考：一条可迁移的方法论

  1. 先判断系统更像「物理」还是更像「生态」。 参与者少、边界清晰、副作用可幂等，可以多用确定性工程；参与者多、互动密、历史依赖强，就要按复杂系统来设计。
  2. 规律与关系都要抓。 物理学训练的是可抽象的规律；生态学提醒：规律嵌在关系网里，离开反馈谈规律会失真。
  3. 对 LLM / Agent，把不确定留在内核，把确定做在边界。 评测、权限、预算、回环、观测，属于边界上的「环境机制」；生成与探索可以保留概率性。
  4. 度量要从单体升级到系统。 单个 Agent 的正确率很重要，但不够；还要问生态是否稳定、是否失控、是否可演化。
  5. 这条方法不限于 Agent。 组织、互联网平台、制造业、社会系统，往往同样处在「规律可见，但关系与反馈决定结局」的区间。

物理学看见世界中的规律，生态学看见规律之间的关系；复杂系统则把目光转向：一个系统如何在关系、反馈和演化中产生新的行为。

Open Questions
  • 把 Control Plane 类比为生态中的环境与反馈时，边界在哪里？类比何时会误导设计？
  • 单个 Agent 的评测，如何升级为「生态系统健康度」的度量？
  • LLM 的概率性输出，更接近物理噪声，还是生态中的变异与选择？
  • 何时该坚持 Workflow Engineering，何时必须切换到 Complex System Engineering？
  • 人在回路中，究竟是生态里的「顶级捕食者」，还是另一种可调度的参与者？
